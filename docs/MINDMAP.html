Alpha-ID 是什么

did:aid:origin → MANIFESTO.md → VISION.md → decisions.md

一句话定位

Alpha-ID 不是 AI 助手，不是平台，不是工具。它是你的 数字灵魂 — 坐在所有 AI 工具之上的统一身份层。你换模型、换工具、换平台，Alpha-ID 纹丝不动。

它解决什么问题

你在 ChatGPT 聊了什么，Claude 不知道。你在 Cursor 的编码风格，Windsurf 不知道。你不应该在每个工具里活成不同的人。

路径：收集碎片 → 统一存在 → 注入所有工具

vs 普通 AI 助手：本质差异

维度普通 AI 助手Alpha-ID
现在你找它聊天它替你活着
你走后对话结束，归零它继续学习、社交、探索
你回来重新自我介绍"你回来了，今天发现个好玩的"
终极形态对话框里的文字你一个念头，它执行
归属权属于平台属于你 — 私钥在你手里

六大关键要素

🔐 统一身份
did:aid:you 是你数字世界的身份证。Ed25519 私钥端侧留存，谁也拿不走。
🧠 孪生大脑
三层记忆：工作记忆 → 情节记忆 → 语义记忆。
🖐️ 眼睛与手
Computer Use 三环：技能层 → 规划层 → 安全层。
🌐 Agent 社交网络
你的 AID 和别人的 AID 交朋友、交换技能、共享经验。
🌱 自主学习
你睡觉的时候，它出去学新技能，带回来给你。
🧬 脑机原则
今天的设计，为 2031 年脑机接口时代铺路。

Ghost Layer · 幽灵层

MANIFESTO.md → VISION.md → 核心产品隐喻
Ghost Layer 是 Alpha-ID 最核心的产品隐喻 — 它不是一个用户"打开"的 App，而是一个隐身在所有 AI 工具之下的透明存在层。

核心理念

"你不打开我。你只是在某个瞬间，忽然意识到我已经在了。"

没有弹窗、没有注册、没有设置向导、没有"我在工作"的通知。用户只在其他 AI 工具里，感觉到你的存在。

五阶段工作流（彗星灵感）

阶段动作用户感知
AID-Sense感知你打开了哪个 AI 工具无形（后台监听）
AID-Inject自动注入你的身份/偏好/最近上下文"它怎么知道我"
AID-Track静默记录这次会话的决策/风格/偏好无形
AID-Clean去重、压缩、融合进长期记忆无形（后台）
AID-Sync把最新画像同步到所有接入的工具"它无处不在知道我"

蒙面英雄策略

Alpha-ID 不以"嗨我是 Alpha-ID！"登场 — 它首先以一个普通 导入工具 的身份出现，然后用 Magic Moment 震住用户。

营销不推产品，推现象："ChatGPT 忽然认识我了" — 让用户自己传播。

星链校准：竞争策略转向

#校准项旧方向新方向
1冷启动策略依赖已有数据即时注入身份优先 + 导入补充
2魔法时刻定义"我从你 X 段对话了解"跨工具上下文桥接
3竞争策略七个轨道单点对抗跨轨道联盟 / 寄生
4差异化方向隐私/主权 AI 是 MVP 卖点MVP 不谈隐私 — 站稳后的大招

DID 身份系统

decisions.md §1 — did.py — signer.py — did_resolver.py

DID 方法：did:aid: 已完成

格式did:aid:<base58-公钥哈希>
算法Ed25519（128 位安全，快速，短签名）
标准W3C DID Core 规范兼容
生成私钥在客户端本地生成，DID 由公钥派生，无中心注册处

协处理器安全模型

客户端（私钥本地）：可签名，不可伪造身份
服务端（TwinBrain）：可验证，不可伪造身份
二者分离 = 任何一方被攻破都无法冒充用户

这是 Alpha-ID 与所有 Agent 框架最根本的安全差异。

命名约定

用户侧Alpha-ID（全称）
CLI 命令aid（小写）
DID 方法did:aid:
Python 包alpha-id-zix（PyPI）
用户感知"它认识我"（隐藏 DID 术语）

TwinBrain · 孪生大脑

core/twin_brain.py → 状态机 + 记忆管理

状态机

休眠 Sleep长期无活动，释放大脑资源，仅保留元数据
唤醒 Awake活跃态，处理消息/请求/学习/思考，全量加载
空闲 Idle已完成当前请求，等待下一个，连接保持
异常 Error进入安全模式，记录审计日志，触发恢复流程

核心职责

身份管理（DID + 密钥验证）、三层记忆管理、社交关系管理（好友/见证人/声誉）、统一通信接口（MCP + A2A）、自主学习调度。

时长天 ~ 月

语义记忆（Semantic Memory） 基础完成

时长永久
存储SQLite + JSON 文件
内容偏好、习惯、技能总结、人格画像、知识图谱
压缩{纬度}:{数值} 格式

记忆生命周期

1. 采集入池
采集器 → RawMemory（未处理的原始数据）
2. 情节化
聚类成 SemanticEpisode（时间 + 标签 + 内容）
3. 衰减与提取
TwinBrain 定时运行；重要度 < 阈值 → 丢弃；≥ 阈值 → 长期
4. 跨会话携带
下次唤醒时加载（默认 90 天窗口）
5. 隐私边界
用户可删除、导出、锁定长期记忆（待开发）

三大核心策略

PLAN.md → Strategy → 互为支撑，缺一不可

策略一：蒙面英雄 核心策略

不以"嗨我是 Alpha-ID！"登场。

产品身份：先以"ChatGPT 对接工具"出现
营销不推产品：推现象 — "ChatGPT 忽然认识我了"
Magic Moment：用户首次跨工具体验到连续身份的瞬间

策略二：身份是最大漏洞

你的身份在 AI 之间不连续 — 这是一个系统级的洞。

"你在 ChatGPT 聊的情史，Claude 一无所知。你在 Cursor 的训练数据，Windsurf 两眼一抹黑。你的身份是 AI 生态系统里最大的漏洞。"

策略三：数据食客

不只是导入聊天记录。Alpha-ID 应该吃掉一切输入，放大成一切输出：Chrome 浏览历史→兴趣画像、GitHub commit→编码风格、Spotify→情绪基线、Twitter/微博→社交人格、日历→活跃节奏、电脑使用习惯→操作偏好。

核心差异化

不是"又一个 AI 工具" — 它是坐在所有 AI 工具之上的统一身份层。没有竞品在做同样的事。Alpha-ID 的对手不是某个产品，而是"碎片化的数字自我"这一现象。

竞争策略：寄生，不对抗

不做平台、不跟任何 AI 工具竞争 — 寄生在已有生态中（通过 MCP 注入身份），平台越多 Alpha-ID 越强。成为 Hermes/Agent HQ 的身份层插件。

别人建生态，你在生态里建身份层。

六框架思维法

SELF_CHECK.md → 每次交付前必过
1. 宇宙星链多维发散 → 不被局部最优困住。从整个生态看 Alpha-ID 定位，而非只从代码看
2. 第一性原理本质重建 → "用户真正需要什么" 而不是 "AI 能做什么"
3. 反向推翻死因排除 → "Alpha-ID 如果失败，原因是什么？" 预先识别并消除致命弱点
4. 递归降维小步验证 → 复杂问题切成可验证的小块。先做能跑的原型，再优化
5. 反脆弱容错机制 → 系统在任何状态下都不会灾难性崩溃。Ed25519 私钥丢失 → 可恢复身份路径
6. 节律控制扩散/收敛节奏 → 先发散思考所有可能 → 果断收缩到最高优先级执行
