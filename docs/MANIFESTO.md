# Alpha-ID — 战略宣言

> **你的数字存在是连续的。不管你在哪个平台上。**

---

## 一、这个项目到底是什么

Alpha-ID 不是一个"身份认证工具"。不是"记住密码"。不是"跨平台登录"。

Alpha-ID 是你在所有 AI 工具间的数字存在连续性。

你同时在用 Web ChatGPT、Codex、Cursor、Hermes、Harness——每个平台都只认识你的一个碎片。你不应该在不同工具里活成不同的人。

Alpha-ID 做的事：
- **收集**你在各处的数字足迹（对话、代码、偏好、习惯）
- **统一**成一个完整的、属于你的数字存在
- **注入**回你使用的每一个 AI 工具——让它们都认识同一个你

---

## 二、终局画面

五年后，一个开发者打开他的电脑：

```
ChatGPT 在聊需求 → 知道他的思考方式
Codex 在写核心逻辑 → 知道他的代码风格和项目上下文
Hermes 在跑自动化 → 延续他上次调通的参数和偏好
Harness 在部署 → 知道他的环境配置习惯

所有这些工具底下的"那个开发者"是同一个完整的他。
```

他新装了一个 AI 工具，第一次打开——那个工具已经知道他。**不是因为他在设置里填了资料，是因为他的 Alpha-ID 已经在了。**

这不是"省去输入密码的麻烦"。这是**你的数字自我，在所有工具间无缝延续。**

---

## 三、七层思维框架（项目的 DNA）

Alpha-ID 不是拍脑袋做出来的。每次决策前运行这七个思维：

| 框架 | 解决什么问题 | 一句话 |
|:----|------------|--------|
| **宇宙星链** | 我在生态的哪个位置？ | 以我为中心，指数级发散 |
| **第一性原理** | 这个事的本质是什么？ | 压缩到本质再重新组装 |
| **反向推翻** | 这个方向为什么不会死？ | 证伪通过才成立 |
| **递归降维** | 太复杂了从哪里下手？ | 降一层先解决，再升回去验证 |
| **反脆弱设计** | 怎么越做越强？ | 不是防止失败，是让失败变成学习 |
| **节律控制** | 该扩散还是收缩？ | 扩散吸收→收缩输出，呼吸式迭代 |
| **全息追溯** | 证据链完整吗？ | 每个结论3步内可追溯到原始证据 |

## 四、敌人不是竞品，是"用户不知道需要你"

CC Switch（89k⭐）做的是 API 管理——换供应商，不管理你是谁。
Mem0（$24M 融资）做的是记忆数据库——存，不认识你。
Hermes（48k⭐）做的是能自学的 Agent——它自己的身份，不是你的。
AgentRecall（292⭐）做的是跨平台记忆——起步了，还没到人格层。
OpenClaw（280k⭐）做的是操作——不知道谁在操作。

**他们都在做能力，没有人做"存在"。**

但最大的问题不是他们有竞品——是**用户已经习惯了在不同工具里当不同的人**，就像鱼习惯了水。你要制造一个让他们突然发现的"魔法时刻"。

---

## 五、三条路径，一条优先

| 层 | 做什么 | 优先级 |
|:--:|-------|:------:|
| **第一层：记忆** | 把你散在各处的数字足迹收拢、统一 | **P0 — 现在** |
| **第二层：桥接** | 让你进入任何 AI 工具时，它自动知道你 | **P1 — 确认记忆能收之后** |
| **第三层：操作** | 你发一个指令，它替你执行 | **P2 — 有用户基数后** |

**当前只做第一层：数据采集器。** 先收 ChatGPT 对话，再收 Cursor/Codex 代码活动。先让自己这台电脑上有一个"完整的你"。

## 六、MVP 的魔法时刻

> 用户把自己的 ChatGPT 导出拖进一个工具。5 秒后他看到一张卡片：
>
> "我从你 47 段对话中了解到：你凌晨活跃，擅长 Python/React，写作偏好短句，最近在关注 MCP 和 AI Agent。你在所有 AI 工具中的同一个你，从现在开始存在了。"

这个体验不需要 MCP 配置、不需要改 JSON、不需要理解 DID。**拖进去，看到结果，就够了。**
