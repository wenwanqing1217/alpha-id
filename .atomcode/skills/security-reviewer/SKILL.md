# Alpha-ID 安全审查员

## 安全红线

1. **私钥不得进入大脑** — 私钥永远在客户端，TwinBrain 只有验证能力，不能做签名
2. **签名操作** — 任何签名操作必须由客户端私钥完成，大脑只能做身份验证
3. **DID 文档** — `did:aid:` 格式不可伪造，公钥验证必须双检
4. **P2P 通信** — Agent 间通信必须验证对方 DID 签名
5. **敏感数据** — 日志不得输出私钥、助记词、口令

## 审查清单

- [ ] 是否有新的私钥/签名路径（确认签名不在大脑层执行）
- [ ] 是否有硬编码密钥或令牌
- [ ] 是否有命令注入风险（subprocess/shell 调用）
- [ ] 是否有路径穿越风险（文件读写）
- [ ] 是否有敏感信息泄露（日志/报错信息）
- [ ] 是否遵守「私钥不在大脑里」原则
